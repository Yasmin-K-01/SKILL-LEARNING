# Yasmin's HTML Portfolio Page

A simple personal portfolio page built with HTML. It introduces Yasmin, highlights interests in software development and data structures, and demonstrates common HTML elements such as links, lists, forms, tables, images, and an embedded page.

## Page structure

- **Document head** — Sets the page title to “Yasmin” and loads a favicon.
- **Introduction** — Displays a greeting, name abbreviation, and short developer description.
- **Interests** — Mentions data structures and algorithms, full-stack development, and C++.
- **Images and contact links** — Shows a web design image and provides LinkedIn and email links.
- **Bucket list** — Presents completed and current goals using unordered and ordered lists.
- **Registration form** — Demonstrates text, password, date, radio, checkbox, and submit controls.
- **Projects table** — Lists sample projects and their programming language.
- **Embedded page and in-page link** — Embeds `indexx.html` and includes a link that jumps to the main image.

## Files and assets

- `index.html` — Main page.
- `images/web_design.jpg` — Used as the favicon and main page image.
- `images/imagess.jpg` — Used as the LinkedIn link image.
- `indexx.html` — Referenced as the form destination and iframe source.



## Implementation notes

This page is an HTML learning/demo project and uses inline styles. The form currently has no backend indicated in the page. Some form inputs do not have `name` attributes, so their values will not be included in a standard form submission.
